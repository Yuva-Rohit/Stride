# Stride
### Personal Productivity Dashboard

Stride is a web-based productivity dashboard designed to help users manage daily tasks, build consistent habits, organize goals, and improve their daily workflow.

The application brings multiple productivity tools into a single interface, providing a centralized space to plan activities, monitor progress, and maintain consistency.

## Overview

Stride aims to simplify personal productivity by combining task management, habit tracking, scheduling, and focus tools in one application.

The interface is designed with a modern layout, responsive components, and light and dark theme support.

## Features

### Task Management
- Create, update, and delete tasks.
- Organize daily activities.
- Manage task completion and progress.

### Habit Tracking
- Create and manage personal habits.
- Track daily habit completion.
- Monitor consistency through a visual tracking system.

### Dashboard
- View productivity information in one place.
- Monitor daily activities and progress.
- Access different productivity tools through a centralized interface.

### Calendar
- View and organize activities by date.
- Keep track of scheduled tasks and important dates.

### Goal Management
- Create personal goals.
- Monitor goal progress.
- Keep long-term objectives organized.

### Pomodoro Timer
- Use focused work sessions.
- Manage work and break intervals.
- Support a more structured workflow.

### Theme Support
- Switch between light and dark themes.
- Save theme preferences using browser storage.

### Data Persistence
- Uses browser Local Storage to retain supported application data between sessions.

## Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Yuva-Rohit/Stride.git
```

**2. Navigate to the project directory**

```bash
cd Stride
```

**3. Run the application**

Open `index.html` in your preferred web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.
